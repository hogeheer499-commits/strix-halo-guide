# Community Code of Conduct

This project welcomes technical disagreement, slower reproductions, failed
experiments, corrections, and evidence that challenges an existing conclusion.
Participants must discuss people and results respectfully.

## Expected Behavior

- Share enough context for claims to be checked.
- Credit original authors and community contributors.
- Separate measured facts, interpretation, and speculation.
- Accept good-faith corrections and preserve material caveats.
- Respect privacy, licensing, platform rules, and disclosure requirements.

## Unacceptable Behavior

- Harassment, threats, personal attacks, discriminatory language, or unwanted
  sexual attention.
- Publishing private information or credentials.
- Impersonation, unsafe downloads, fabricated evidence, hidden sponsorship, or
  coordinated voting/brigading.
- Pressuring contributors to produce positive results or remove accurate
  negative findings.

## Enforcement

Maintainers may edit or remove abusive content, close or lock threads, reject
contributions, or restrict participation. Context, severity, repeated behavior,
and community safety will determine the response.

For ordinary technical disputes, open a repository issue with evidence. For a
safety or conduct concern that should not be public, use a private contact
method listed on the maintainer's GitHub profile; if none is available, use
GitHub's block and report tools. Do not publish sensitive personal details in a
public issue.

This code applies in repository issues, pull requests, discussions, and project
spaces controlled by the maintainers.
