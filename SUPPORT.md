# Support This Guide

This guide stays free, public, and evidence-first.

If it saved you setup time, helped you choose hardware, or helped you avoid a bad backend/model path, the best ways to support it are:

1. Star the repository so other Strix Halo owners can find it.
2. Share benchmark results, power data, failed experiments, or corrections.
3. Open issues or pull requests when setup steps become stale.
4. Support continued testing through GitHub Sponsors once sponsorship is enabled for this account.

## Funding Policy

Funding does not influence benchmark conclusions.

Support may fund hardware, storage, model downloads, testing time, and ongoing maintenance. Benchmark results still need raw evidence, version details, and clear caveats before they become public claims.

Sponsored tests, if added later, must be labeled as sponsored and must still publish the raw data and setup details.

## What Funding Helps With

- Keeping the guide current as `llama.cpp`, Ollama, Mesa, ROCm, vLLM, and model releases change.
- Downloading and testing large models and quantizations.
- Storing raw logs, CSVs, model metadata, and generated charts.
- Running repeat tests after regressions, driver changes, or community reports.
- Improving beginner setup docs without removing the raw evidence trail.

## Non-Financial Contributions

Community data is often more valuable than money. Reports from Beelink, GMKtec, Corsair, Framework, HP ZBook, and other Ryzen AI MAX systems help turn this guide from one machine's results into a reproducible Strix Halo map.

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the highest-value reports currently wanted.
