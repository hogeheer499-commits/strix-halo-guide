# Strix Halo Bench Context Pack

This bundle keeps only the bench context the other repo asked for:

- system metadata
- source-style claim index
- reproducibility notes
- exact model, backend, and settings
- raw benchmark rows
- supplemental telemetry, when available

It removes the earlier working-variation commentary, pairwise discussion, and
source-report copies.
